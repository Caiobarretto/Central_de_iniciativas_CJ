Central da Controladoria Jurídica
Configuração final

Modelo gratuito para começar: Central no Render, dados compartilhados no Neon, Excel no navegador e RPA da Lexio no seu computador.

Para o time: apenas navegador. Instalação de Python e robô é necessária somente no computador anfitrião, o seu. O computador precisa estar ligado, conectado e com a sessão do Windows aberta para a Lexio funcionar.

1. Preparar os arquivos e o GitHub

  1. Baixe e extraia o pacote atualizado. Entre na pasta Central_CJ_GitHub_Gratuito.
  2. Antes de atualizar uma Central já em uso, entre como administrador e exporte um backup JSON.
  3. No GitHub, abra seu repositório, clique em Add file → Upload files e envie o conteúdo da pasta: index.html, server.py, database.py, rpa_queue.py, requirements.txt, render.yaml, initial_data.json, favicon.png e as pastas ferramentas e robo. O index.html deve ficar na raiz do repositório.
  4. Se substituir o pacote antigo, remova do repositório os arquivos antigos ferramentas/Segmentos_Grandes_CJ.zip e a pasta ferramentas/Segmentos_Grandes. Preserve a pasta .github se estiver usando o fluxo de Pages.
  5. Não envie pastas data, _site, __pycache__ ou .venv. Não envie config.json, SEGREDOS_RENDER.txt ou LINK_EQUIPE.txt da pasta robo; eles serão criados no seu computador depois.
  6. Confirme a atualização com Commit changes.

O GitHub guarda o projeto. O endereço completo para uso do time será o do Render. GitHub Pages serve apenas como visualização estática: não executa a fila remota nem salva o catálogo compartilhado.

2. Criar ou manter o banco gratuito Neon

  1. Acesse console.neon.tech e crie uma conta. Escolha o plano Free e crie um projeto PostgreSQL, por exemplo central-cj. Se você já configurou o Neon, reutilize o banco existente.
  2. Abra Connect, selecione uma conexão PostgreSQL, preferencialmente com Connection pooling, e copie a connection string.
  3. Ela começa com postgresql:// e deve incluir sslmode=require. Guarde para a variável DATABASE_URL no Render.

O catálogo, anexos e fila da Lexio serão armazenados nesse banco. Não use o PostgreSQL gratuito temporário do Render para dados definitivos. Este pacote não depende de disco pago do Render.

3. Hospedar a Central no Render gratuito

  1. Abra dashboard.render.com. Se já existe um Web Service para a Central, atualize esse serviço. Caso contrário, escolha New → Web Service e conecte o repositório GitHub.
  2. Configure runtime Python e plano Free. Root Directory vazio, se index.html está na raiz.
  3. Build Command: pip install -r requirements.txt.
  4. Start Command: gunicorn server:application --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120.
  5. Health Check Path: /health.
  6. Em Environment, configure as variáveis abaixo. As três variáveis RPA serão geradas na próxima etapa.
VariávelValor
PYTHON_VERSION3.12.8

Se ainda não souber a URL, faça o primeiro deploy, copie o endereço do serviço, ajuste PUBLIC_URL e salve com novo deploy. O catálogo pode funcionar antes de configurar o RPA; a Lexio informará que o robô ainda não foi configurado.

O Render gratuito pode entrar em repouso após 15 minutos sem uso e demorar ao ser acessado novamente. A fila faz parte do serviço web, não exige contratar Background Worker. Os planos gratuitos têm cotas; acompanhe os painéis Render/Neon e ligue o executor quando for utilizar.

4. Instalar o executor somente no seu computador

  1. Instale Python 3.12 ou superior em python.org, com o Python Launcher. Na instalação, marque Add Python to PATH.
  2. Instale ou atualize o Google Chrome. O robô usa um perfil separado do Chrome para a Lexio.
  3. Na pasta extraída, abra robo → INSTALAR_WINDOWS.bat. Aguarde a criação do ambiente e a instalação do Playwright. Não é necessário instalar Excel para este processamento.
  4. Se a instalação falhar, confira a conexão, o Python Launcher e eventuais bloqueios de instalação do escritório.

O time não realiza essa etapa. Não é preciso configurar VPN, acesso remoto à área de trabalho, túnel, endereço público do seu computador ou portas no roteador.

5. Conectar seu computador à Central

  1. Abra robo → CONFIGURAR_WINDOWS.bat.
  2. Informe a URL HTTPS do Render e seu e-mail de acesso à Lexio.
  3. O programa cria config.json, SEGREDOS_RENDER.txt e LINK_EQUIPE.txt somente nessa pasta local.
  4. Abra SEGREDOS_RENDER.txt e copie os três valores para as variáveis de mesmo nome em Render → Environment. Salve e aguarde o deploy.
  5. Não envie esses arquivos ao GitHub. Não compartilhe os segredos do executor. Para o time, compartilhe somente o endereço de LINK_EQUIPE.txt.
  6. Abra robo → INICIAR_WINDOWS.bat e digite a senha da Lexio no terminal. A senha não é exibida e fica somente na memória durante essa sessão; documentos e credenciais temporárias usados pelo robô são apagados após cada execução.
  7. Deixe o terminal aberto. Abra a Central pelo link de LINK_EQUIPE.txt e, no card Lexio, clique em Verificar disponibilidade. Deve aparecer Robô remoto disponível.

A chave da equipe faz parte do link, para autorizar os envios sem criar login para o time. Quem recebe esse link pode usar o robô com a conta Lexio do anfitrião. Distribua o endereço aos integrantes autorizados. O endereço público sem esse link continua permitindo visualizar as iniciativas e usar o Excel.

Depois de alterar a URL da Central, atualize PUBLIC_URL no Render e central_url em robo/config.json; atualize o link da equipe mantendo sua chave. Não gere novos segredos sem atualizar os três valores no Render. Não troque RPA_QUEUE_KEY com documentos ainda na fila.

6. Fazer o primeiro teste da Lexio

O botão Gerar e enviar Lexio da ferramenta de procurações/substabelecimentos também usa a fila remota. Procurações e documentos externos mantêm o comportamento de somente subir o documento; substabelecimentos internos seguem para assinatura.

  1. Com o executor ligado, use um documento de teste autorizado e um assinante de teste controlado pelo QCA. O envio real dispara a solicitação de assinatura; não use dados fictícios de terceiros.
  2. Na Central, abra o card Lexio. Selecione um .docx de até 10 MB, informe pasta e tipo exatamente como cadastrados na Lexio.
  3. Preencha Assinante 1, Assinante 2 etc. ou importe CSV/JSON. Você pode ajustar cada documento na revisão. São aceitos até seis assinantes por documento.
  4. Revise, marque a autorização do lote e clique em Enviar lote revisado.
  5. O Chrome abrirá no seu computador. Se a Lexio exigir MFA, confirmação ou CAPTCHA, conclua essa etapa nesse computador. Os demais usuários acompanham o estado pela Central; este pacote não transmite sua área de trabalho.
  6. Confira o link retornado, documento, assinantes e posicionamento dos carimbos na Lexio. Depois teste outro documento e, por último, um lote pequeno.

O robô trata um documento por vez. Se ele perder conexão, exceder 15 minutos ou não confirmar o resultado, a Central sinaliza Conferir na Lexio e interrompe o lote. Não há repetição automática de um envio que possa já ter ocorrido. Parar após documento atual interrompe os próximos documentos, não desfaz assinaturas ou envios.

Documentos aguardando ficam criptografados na fila por até 8 horas. O conteúdo é removido da fila quando o robô o retira; estados/resultados são conservados por até 24 horas, com limpeza no próximo acesso. Se fechar a tela durante um envio, reabra a ferramenta na mesma aba para recuperar o resultado pendente. Uma nova aba não recupera essa sessão.

7. Testar o Excel de segmentos

  1. Abra a Central no Chrome ou Edge atualizado, em HTTPS, fora do modo anônimo.
  2. Entre no card de segmentos e selecione até 3 arquivos .xlsx ou .xlsm. Não há instalação nem envio dos relatórios ao Render.
  3. Na linha 1 devem existir os campos Segmento, Célula e ID. Se desejar, informe o nome da aba; sem nome, a primeira compatível é usada, priorizando abas visíveis.
  4. Clique em Tratar relatórios. Na primeira utilização, o navegador carrega automaticamente o motor WebAssembly/Python pela internet. Depois processa um relatório por vez no armazenamento temporário privado do navegador.
  5. Baixe os arquivos tratados. Clique em Limpar arquivos para remover os temporários desse lote.
  6. Confira uma amostra da base e a aba Resumo Segmentos no Excel. Neste modo, o resumo apresenta contagens em células; não é criada uma nova tabela dinâmica.

O seletor aceita até 1 GB por arquivo. A capacidade real depende de espaço livre no armazenamento do navegador, memória e estrutura da planilha. O motor foi validado com um arquivo sintético de 143 MB e 100 mil linhas; isso não substitui a conferência de um relatório real do Performa Flow. Arquivos .xls, protegidos por senha ou com aba protegida devem ser salvos como .xlsx sem proteção. Fórmulas precisam ter resultados salvos.

A primeira carga depende de acesso a cdn.jsdelivr.net. Os relatórios permanecem no navegador; apenas os componentes de processamento são carregados da internet. Temporários deixados por fechamento abrupto podem ser removidos nas configurações do navegador, apagando os dados deste site (isso também apaga preferências locais).

8. Finalizar catálogo, administração e uso diário

  1. A página inicial permanece nas iniciativas. O texto discreto de acesso administrativo está no rodapé. Use ADMIN_USER e ADMIN_PASSWORD definidos no Render.
  2. Se já existia um catálogo no mesmo banco, ele permanece. Para migrar de uma Central local ou outro banco, importe o backup JSON pelo painel administrativo e salve; faça isso antes de novas edições do time.
  3. Cadastre/edite iniciativas, escolha pop-up ou nova aba e adicione anexos de download quando necessário. Os limites dos anexos dos cards são independentes dos relatórios de segmentos.
  4. Cadastre o relatório mensal na seção de resultados do administrador. O aviso da página aponta para o mês anterior; mantenha o conteúdo desse mês publicado.
  5. Teste em outra janela: confirme o catálogo compartilhado, a ausência de edição para o time e as novas ferramentas.
  6. Nas configurações Windows de energia, evite a suspensão durante o expediente de uso do robô. Mantenha internet e sessão aberta. Ao terminar o dia, Ctrl+C encerra o executor; a Lexio ficará offline para o time até o próximo início, mas catálogo e Excel continuam funcionando.

O executor não roda enquanto seu computador estiver desligado ou suspenso. Para reiniciar depois, use INICIAR_WINDOWS.bat e informe novamente a senha. Não foi configurada inicialização automática, pois esta versão pede a senha em cada sessão.
